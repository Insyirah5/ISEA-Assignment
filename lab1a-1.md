Reflection Questions:

•	What are the advantages of using virtual machines for testing and development?

Answer: A VM keeps the host computer safe if code crashes or if untrusted software infects it. And a single powerful computer or cloud server can host several VMs at once, which saves money on purchasing, powering, and cooling extra physical machines.


•	What challenges did you face during installation or network setup?

Answer: I did not double-check that I had selected the correct settings for the VM installation, which made the installation take much longer than necessary.


•	What are the differences between NAT and Bridged networking in VirtualBox?

Answer: In VirtualBox, NAT hides the VM behind the host computer's connection, while Bridged networking makes the VM appear like a separate physical computer on your local network.


•	What did you learn about Linux distributions (distros) from your reading?

Answer: A Linux distribution (distro) is a complete operating system built around the Linux kernel, combined with everyday tools, apps, and a system to install and update software. The Linux kernel is the core software that talks to computer hardware. The system tools and apps are just like Windows or macOS.
