I learnt that the ls command lists the files or directories, and there are multiple flags to filter and display only what you want to see. From the examples, I used ls -lah, which is a combination of the -l, -a and -h flags. 
-l: Displays detailed information, including file permissions, owner, group, file size, and modification date.
-a: Shows all files, including hidden files (those beginning with a dot).
-h: Displays file sizes in a human-readable format, such as KB, MB, or GB.
-t: Sorts files by modification time, with the most recently modified files appearing first.

The difference between gedit and nano is that gedit is a graphical desktop editor like Notepad, while nano is a text-based editor that runs right inside the terminal using keyboard shortcuts.

The cp command copies files or directories while keeping the original intact, whereas the mv command moves or renames them so they no longer remain at the original location.

The sudo apt update command connects to the configured software repositories and downloads the latest package information, including available software versions and security updates. This allows Ubuntu to check which packages have newer versions available. However, it does not install the updates, as the sudo apt upgrade command is used for that.
